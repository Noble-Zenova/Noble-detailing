# Noble booking

`index.html` is the standalone interface; `embed.html` is the embedded website interface. Both use `catalog.js`, `booking.js`, `booking.css` and `config.js`. Live mode calls the Netlify backend under `/api`.

Deploy the whole parent website project, including its functions and dependencies. See `../BOOKING-INTEGRATION.md` for activation, environment variables, pricing, scheduling, tests and limitations. Uploading this folder alone does not provide booking or payments.
